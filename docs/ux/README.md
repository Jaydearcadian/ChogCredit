# Chog Credit UX documentation

This folder holds the user-facing documentation for the Chog Credit app: the use cases and the diagrams that show screens, states and flows.

- [USE_CASES.md](USE_CASES.md): Use cases UC-001 to UC-016, with actors, preconditions, main flows, error flows and postconditions.
- [diagrams/INDEX.md](diagrams/INDEX.md): List of the diagrams in `diagrams/`, with a one-line description of each.

Status: testnet only, with mock assets and a mock oracle. Not audited.
