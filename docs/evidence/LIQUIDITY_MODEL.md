## Method and limits

- Single-tick constant-product approximation: within the current tick the pool is x*y=k with x = L/sqrtP and y = L*sqrtP. Impact = 1 - (sold-token price after / before), **pool fee excluded**.
- **Tick crossing is ignored.** A sell that would leave the current tick range is computed with the same L and marked `(extrap.)`. This understates depth only when liquidity is concentrated elsewhere; where it sits outside the current tick, these figures can be wrong in either direction.
- Collateral sold: WMON into the USDC/WMON pools, and the CHOG token into the CHOG/WMON pool. WMON USD = Chainlink MON/USD (`chainlink_MON_USD` in config). CHOG USD = pool mid in WMON times that price.
- Sizes are the USD value of collateral sold at the pool mid price, with no slippage on the valuation.
- Assumptions, not measurements: typical position size $10,000 (no value in repo); illustrative LTV 50% for converting collateral size to a borrow cap.
- The pancakeV3 1.00% WMON pool listed in the reference doc has no address in `config/monad-reference.json`, so it was not read.
